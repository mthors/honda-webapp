# Supabase Database Migrations

This directory will store version-controlled SQL migration files for the Honda Mega Persada Mandiri digital showroom database schema.

- Migration files are ordered sequentially (e.g. `20261024000001_initial_schema.sql`).
- All migrations will be committed to Git.
- Migrations will be implemented starting in Milestone 2 (M2 — Database, Auth and Security Foundation).
